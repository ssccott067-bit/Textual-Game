# Textual-Game
A textual game for a first year university project, called Mysterious Crow, also available in French language. 

To play the game, simply compile and execute the file named 'corbeau_mysterieux.c' in the folder 'Original_Form'.

The structure of this game is all compiled in a single file which makes it difficult to maintain and even to make evolve. A refactoring will be done in the future to make the game at least easier to develop for later use.
